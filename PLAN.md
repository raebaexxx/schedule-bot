## 4. Формат данных

`schedule.json` (одна группа):
```json
{"group":"БА-231","semester":"7 семестр 2026/2027",
 "semester_start":"2026-09-01","semester_end":"2026-12-28",
 "schedule":{"monday":{"name":"Понедельник","slots":[
   {"time":"08:30-10:05","pair":1,"lessons":[
     {"kind":"лек., пр.","subject":"…","teacher":"МАХОВ М.А.","room":"111",
      "ranges":[["2026-09-07","2026-11-09"]],"exact_dates":["2026-11-16"],
      "link":"https://my.mts-link.ru/…"}]}]}, …}}
```

`schedule_all.json` — то же, но обёрнуто: `{"courses":{"1":{"semester":…,
"groups":{"БК-261":{"display":"БК - 261","days":{…}}}}, …}}`.
Активность пары на дату D: D внутри одного из `ranges` ИЛИ D в `exact_dates`.
Семестр осенний: 01.09–30.12 (в PDF бывают даты до 30.12).

## 5. Парсеры — ключевые знания

PDF — Excel-выгрузка: сетка |Дни|Часы|группа×(Дисциплины|Преподаватели|Ауд.)|.
Каждый курс — отдельный PDF (`{N}curs{год}.pdf`), 1 страница, 3–5 групп.

Общий алгоритм (`parse_pdf.py` -> `parse_all.py` расширяет его до
мультиколонок):
1. `pdftotext -bbox-layout` → слова с координатами → кластеризация в
   **визуальные строки** по yMin (tol 1pt; Excel рвёт строку на несколько
   `<line>`).
2. Колонки: подзаголовки «Дисциплины/Преподаватели/Ауд.» дают якоря;
   **indent индивидуален для каждой колонки** (расстояние «Дисциплины →
   первое слово контента»), границы = disc_{i+1}.x0 − indent_{i+1}.
   В indent-расчёте исключать маркеры дней, «Дни/Часы», TIME_RE (иначе
   ПНД-маркер x=104.8 раздувает indent_0).
3. Якоря времени: слова `TIME_RE` в зоне «Часы»; **TIME_RE допускает
   «8.30» без нуля** (дефект субботних меток). Якоря группируются по дням
   (маркеры ПНД..СБТ, секции по серединам центров маркеров) с исправлением
   утечек: убывание времени в начале дня → якорь в предыдущий день и т.п.
4. **Сегментация занятий глобальна** (маркеры типа `лек.,`/`пр.`/`лаб.`/
   `Проект`) — занятие никогда не разрезается между строками; virt-строки
   («вирт ауд.») уводятся в НАСТУПАЮЩЕЕ занятие, если без цифры.
5. **DP-распределение** занятий по строкам: cost = Σ|центр занятия − якорь|
   + |центр диапазона строки − якорь| (метка времени центрирована в строке
   Excel). Пустые строки допустимы.
6. Многопроходный разбор: lead-«вирт. ауд.» + числа перед типом → пропуск;
   учитель (ФИО в любом порядке, инициалы могут быть через 1–3 слова
   предмета, окно ±8 токенов); аудитория (виртуальная приоритетнее числовой,
   «211/305», «310\111», мусорные чистые числа перед «вирт.» съедаются);
   ссылки (части «https://my.mts-» + «link.ru/…» + «vk3» склеиваются даже
   если разнесены); даты («с X по Y», «X», «X и Y»); subject = остаток.
7. **Учитель-«сэндвич»** (1 курс, 2 курс): фамилия НАД предметной строкой,
   инициалы ПОД ней, в узкой учительской подколонке (X-зона между
   «Дисциплины» и «Ауд.»); инициалы могут overflow в соседнюю колонку —
   ищутся в ±1 колонке. Аналогично «вирт ауд. N» переползает в соседнюю
   колонку — цифра возвращается владельцу (первый фикс overflow в
   col_words_all).
8. Подписи «Начальник УМО/ОРО…» — глобальный cutoff (все колонки режутся от
   самой верхней строки подписи).
9. Валидация: **метод B** — каждое занятие проверяется по независимому
   `pdftotext -layout` срезу колонки (срез по позициям «Дисциплин», с
   per-line резкой по пробельным зазорам `_cut_line`, иначе слова режутся
   посередине; перекрытие ±10/+14 симв.); sanity (даты 01.09–31.12,
   teacher/kind/subject непустые). Префикс-проверка предмета (6 симв.)
   из-за переносов; «1н-1п,2н-2п» нормализуются по запятым.

**Важно: старый `data/schedule.json` и старые артефакты НЕ эталон.** Эталон —
только PDF. При изменении PDF верстки править `GROUP_COLUMN`/`indent`-логику.

## 6. Функции ботов

- Оба: `/start`, `/today`, `/tomorrow`, `/week`, `/date DD.MM`,

  догон при рестарте, молчание в пустые дни, Forbidden → отписка).
- Уведомления об изменениях (общий): parse_all при записи JSON строит дифф
  (changes.py) → `data/pending_changes.json`; bot_all при старте рассылает
  каждому пользователю изменения его группы (формат: «ПН 14:05: − … / + …»),
  удаляет очередь. История: 02.09 разосланы изменения по 16 группам
  (211 строк диффа) 7 пользователям.
- Mini App: liquid glass (frost + SVG-displacement для Chromium, детект через
  userAgentData; iOS WebView — frost), пикер группы по клику на чип в шапке,
  подсветка текущей пары и таймеры, вкл/выкл — localStorage.

## 7.1. VPN-сертификаты (x-ui/xray на 443) — НЕ часть бота, но важно

На 443 работает xray (VPN: vless+tls, hysteria — 3x-ui панель). Сертификат —
Let's Encrypt для **IP 144.31.207.159** (shortlived profile, 7 дней!) через
acme.sh (`/root/.acme.sh/`, крон 10:53 ежедневно).

Цепочка автопродления (настроено 06.09, было сломано):
- `acme.sh --issue -d 144.31.207.159 --webroot /opt/schedule-all/webapp`
  (webroot через nginx-80! НЕ standalone — тот конфликтует с nginx-80 и
  требует его остановки)
- install-cert копирует в `/root/cert/ip/{fullchain,privkey}.pem`
- `Le_ReloadCmd='systemctl restart x-ui'` — xray перечитывает серт
- xray читает серты из конфига inbounds в `/etc/x-ui/x-ui.db` (paths те же)

Грабли: x-ui `restart` (панель) НЕ перезагружает xray-сертификаты в памяти —
нужен рестарт самого xray-процесса (systemctl restart x-ui — рестартит оба).
`x-ui restart-xray` рвёт SSH-сессию при выполнении из ssh-команды (443 флап).

**Port hopping (настроено 06.09):** hysteria2 в РФ страдает от ТСПУ-дропа
QUIC-хендшейков. Решение: systemd-юнит `hysteria-porthop.service` — iptables-nat
`UDP 20000:50000 → REDIRECT 443` (идемпотентный, переживает ребут). Клиент должен
включить hop: Happ — в профиле hysteria2 поле портов `mport=20000-50000`
(или адрес портов через дефис), SNI/address = 144.31.207.159 (серт LE на IP).
Важно: 3x-ui НЕ добавит в xray inbound с дублирующимися client email —
при копировании inbound в панели переименовывай email'ы клиентов
(например, суффикс `-hop`), иначе inbound молча выкидывается из конфига xray.

## 8. Известные грабли

- Telegram-клиенты кэшируют меню команд и Mini App — после обновления
  перезапускать чат.
- WKWebView (iOS) не умеет SVG-displacement в backdrop-filter — только frost.
- `@supports` в Safari лжёт про backdrop-filter: url(#…) — детект Chromium
  через navigator.userAgentData.
- Excel-PDF: текст ячеек overflow за границы колонок (ФИО, вирт-цифры) —
  парсинг через x-зоны, а не по строкам текста.
- git на VPS: protocol.version=0 обязателен; safe.directory для root.
- В PDF-данных вуза баг: инициалы преподавателей не соответствуют фамилиям
  (ЗАМЛЕЛАЯ А.Т., ПОДШИВАЛОВА М.В.) — не пытаться «чинить».

## 9. Обновление на новый семестр (чек-лист)

1. Скачать новые `{N}curs{год}.pdf` в папку.
2. `.venv/bin/python scripts/parse_all.py /путь/к/папке` — сверить сводку
   (число занятий по группам, метод B, sanity).
3. Поправить в parse_all.py/parse_pdf.py: SEMESTER_START/SEMESTER_END,
   при новой верстке — PAIR_NUMBERS/EXPECTED_SLOTS/границы.
4. Прогнать тесты; закоммитить JSON; push.
5. На VPS: `git pull` в обоих клонах (protocol.version=0), restart обоих
   сервисов. Уведомления об изменениях уйдут сами.
6. Заполнить data/pending_changes.json вручную, если обновление делалось
   мимо git.
